**Versão atual:** 1.9.1 · Honda Civic G8 2011 · Android 7.0+.

**Na central:** abra `github.com/lincolnvtech/diagram` e clique no link acima.

**Se usa a v1.7, v1.8 ou v1.9:** abra o Civic Drive → **Menu → Atualizar pelo GitHub → Baixar → Instalar**. A versão 1.9.1 usa a mesma assinatura permanente; não precisa desinstalar nem perder dados.

### Correção visual v1.9.1

- Mantém a referência **aprovada**: fundo preto, aros de medidores transparentes/escuros e esfera elétrica detalhada.
- A esfera reage à velocidade (ciano abaixo de 60 km/h, azul escuro de 60 a 109, vermelho a partir de 110), com animação discreta.
- Hora real, arrefecimento e RPM do OBD2, consumo estimado quando disponível e atalhos do launcher.
- Sem a legenda demonstrativa das cores ou dados fictícios sobrepostos.
- Preserva dashboards, leitura de falhas, histórico e atualização pelo botão.

**Observação:** a arte da interface foi reproduzida por recursos do aplicativo; ainda precisa de teste na central para confirmar proporções e desempenho. O velocímetro original do carro permanece a referência para dirigir.
